# JD Analyzer

채용 공고(JD)를 붙여넣으면 회사의 최근 이슈, 사업 현황, 인재상을 자동으로 조사해 요약하고, Notion 데이터베이스에 기록해주는 Claude Code 스킬입니다.

## 목적 & 해결하려는 문제

채용 공고를 볼 때마다 반복되는 불편함이 있습니다.

- JD만으로는 회사가 지금 어떤 상황인지, 무엇을 중요하게 보는지 알기 어렵다
- 최근 이슈를 파악하려면 뉴스를 따로 검색해야 한다
- 사업 현황과 인재상을 알려면 홈페이지와 자료를 다시 뒤져야 한다
- 조사한 내용을 매번 손으로 하나로 합쳐 정리해야 한다
- 이 과정을 공고마다 반복해야 한다

이 스킬은 JD 하나를 입력하는 것만으로 위 조사·정리 과정을 자동화합니다.

## 무엇을 만들어주는가

JD를 입력하면 아래 네 가지를 한 번에 정리합니다.

1. **JD 요약** — 공고 핵심 내용 (역할, 필요 역량, 근무 조건 등)
2. **최근 이슈** — 회사 관련 최신 뉴스
3. **사업 현황** — 최근 방향성, 투자, 사업 동향
4. **인재상** — 회사가 중요하게 여기는 가치·역량·문화

## 사용 방법

Claude Code(VSCode 터미널)에서 JD 본문을 붙여넣으며 요청합니다.

잡코리아, 사람인, 링크드인 등 채용 사이트는 로그인 장벽이나 페이지 구조상 **링크만으로는 본문을 안정적으로 가져올 수 없어**, 본문 텍스트를 직접 붙여넣는 방식을 사용합니다.

**예시**

```
이 공고 분석해줘:

(채용 공고 페이지에서 Ctrl+A, Ctrl+C로 본문 전체를 복사해 붙여넣기)

회사명, 포지션 등은 본문에서 AI가 자동으로 추출하므로 따로 구분해서 입력할 필요는 없습니다.
```

**참고 (이미지형 공고)**: 공고 본문이 이미지로 되어 있어 텍스트 복사가 안 되는 경우, 해당 부분을 스크린샷으로 캡처해 붙여넣어도 동일하게 분석됩니다.

### 처리 순서

1. JD에서 회사명, 포지션, 핵심 요약 추출
2. 회사명 기반으로 웹 검색 실행
   - `{회사명} 최근 뉴스`
   - `{회사명} 사업 현황`
   - `{회사명} 인재상 채용문화`
3. 위 결과를 정해진 JSON 스키마로 통합
4. Notion MCP를 통해 데이터베이스에 1개 행(row)으로 저장
5. 저장 완료 후 요약 결과를 화면에 표시

## 출력 예시 (JSON)

```json
{
  "company": "string",
  "position": "string",
  "jd_summary": "string",
  "recent_issues": [
    { "headline": "string", "date": "string", "source_url": "string" }
  ],
  "business_status": "string",
  "ideal_candidate": {
    "core_values": ["string"],
    "required_skills": ["string"],
    "preferred_traits": ["string"]
  },
  "source": {
    "jd_url": "string",
    "researched_at": "date"
  }
}
```

## 주의사항 및 제약사항

- **입력 방식**: 채용 사이트 링크는 신뢰도 낮음 — 본문 텍스트 또는 스크린샷 붙여넣기를 사용합니다.
- **정보 신뢰도**: 웹 검색 결과를 기반으로 하므로, 최신성은 검색 시점에 따라 달라질 수 있습니다. 중요한 의사결정 전에는 원문 확인을 권장합니다.
- **추측 금지**: 검색으로 확인되지 않는 정보는 임의로 채우지 않고 "정보 없음"으로 표기합니다.
- **출처 기록**: 모든 검색 기반 정보는 출처 URL을 함께 기록합니다.
- **Notion 연결 필수**: Notion MCP가 연결되어 있지 않으면 저장 단계가 동작하지 않습니다.
- **중복 처리**: 동일 회사·포지션 조합이 이미 Notion에 있는 경우 처리 방식은 `SKILL.md`의 규칙을 따릅니다. *(→ 추후 확정 예정)*
- **개인 용도**: 이 스킬은 로컬(Claude Code) 환경에서 개인 사용을 전제로 설계되었습니다.
